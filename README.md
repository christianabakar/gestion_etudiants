# Gestion des étudiants

Application Python de gestion des étudiants, développée dans le cadre du cours
d'Industrialisation des développements (Master MDSIA – ESMT).

## Fonctionnalités
- `main.py` : point d'entrée de l'application
- `rechercher_etudiant_etudiants.py` : recherche d'étudiants par nom
